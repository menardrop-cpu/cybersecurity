---

## Approche

Je conçois la sécurité comme une **problématique de gouvernance d'abord, technique ensuite**. Cela signifie :

* Chaque vulnérabilité identifiée se traduit en **impact métier** (scoring CIA, criticité)
* Chaque audit produit un **livrable décideur** : exécutive summary + recommandations graduées
* L'exploitation technique ne m'intéresse que si elle quantifie un risque réel
